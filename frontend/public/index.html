RMS = √(Σx²/n). One RMS record per 0.25 s window. Records 1–N are training records without a score. On record N+1, the first N records give the fixed mean and population standard deviation; N+1 is the first compared record. Rust defaults to 500 records. Changing k moves only the threshold.

06 / WHERE THE DEMONSTRATION ENDS

From files to the factory

The actual Rust engine

Silent-Ear reads accelerometer files, computes one RMS value per channel per file, learns a fixed reference, and flags values strictly above mean + k·σ.

It does not compute crest factor, kurtosis or envelope spectra today. It does not diagnose a race or ball, predict a seizure, or estimate remaining useful life.

Results leave through REST /api/status and WebSocket /ws. Optional MQTT publishes silent-ear/status and silent-ear/health; silent-ear/alerts publishes when status is CRITICAL. Prometheus reads /metrics.

Measured performance, within its limits

40.96 M values in 1.29–1.44 s, Apple M3 Pro, release build, synthetic IMS-format files, RMS stage only; not measured on real IMS files or a Raspberry Pi.
